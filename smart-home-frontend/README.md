# Smart Home Frontend (Mobile App - Flutter)

Thư mục này chứa mã nguồn ứng dụng di động cho hệ thống Nhà Thông Minh (Smart Home).

## Hướng dẫn khởi tạo ứng dụng:
1. Mở terminal và di chuyển vào thư mục này:
   ```bash
   cd smart-home-frontend
   ```
2. Khởi tạo dự án Flutter:
   ```bash
   flutter create .
   ```
3. Chạy ứng dụng:
   ```bash
   flutter run
   ```

Chi tiết tài liệu API Backend và các màn hình cần xây dựng xem tại file `HUONG_DAN_LAM_APP_FLUTTER.txt` ở thư mục gốc.
