Chào bạn! Dưới đây là toàn bộ thông tin về môi trường cần cài đặt, luồng màn hình
cần thiết kế và danh sách các API Backend đã sẵn sàng để bạn kết nối.

--------------------------------------------------------------------------------
PHẦN 1: CÀI ĐẶT MÔI TRƯỜNG PHÁT TRIỂN
--------------------------------------------------------------------------------
1. Tải và cài đặt Flutter SDK:
   - Link tải bản Stable: https://docs.flutter.dev/get-started/install
   - Giải nén (VD: C:\src\flutter) và thêm đường dẫn "flutter\bin" vào biến môi trường PATH của Windows.

2. Cài đặt Android Studio:
   - Tải tại: https://developer.android.com/studio
   - Mở Android Studio -> SDK Manager -> Cài đặt Android SDK và "Android SDK Command-line Tools".
   - Tạo một máy ảo Android (AVD) để test hoặc dùng điện thoại Android thật (bật USB Debugging).

3. Cài đặt Code Editor (Khuyên dùng VS Code):
   - Mở VS Code, vào mục Extensions cài 2 extension:
     + "Flutter"
     + "Dart"

4. Kiểm tra môi trường:
   - Mở CMD/Terminal gõ:
     flutter doctor
   - Khi các mục Android toolchain hiện dấu tick xanh [✓] là hoàn tất.

5. Các thư viện Flutter khuyên dùng (thêm vào pubspec.yaml):
   - http: ^1.2.0 (hoặc dio: ^5.4.0) -> Gọi API Backend
   - shared_preferences: ^2.2.2 -> Lưu mã JWT Token đăng nhập
   - provider: ^6.1.1 (hoặc flutter_bloc, get) -> Quản lý state giao diện

--------------------------------------------------------------------------------
PHẦN 2: ĐỊA CHỈ BASE URL ĐỂ KẾT NỐI BACKEND
--------------------------------------------------------------------------------
Backend hiện chạy ở cổng port 8080:

- NẾU BẠN CHẠY MÁY ẢO ANDROID (Android Emulator):
  Base URL = "http://10.0.2.2:8080"
  (Lưu ý: Không dùng "localhost" vì máy ảo hiểu nhầm là chính nó).

- NẾU BẠN CHẠY TRÊN ĐIỆN THOẠI THẬT (Hoặc 2 máy tính khác nhau):
  1. Hai máy phải kết nối CHUNG 1 mạng Wi-Fi (hoặc phát Wi-Fi từ điện thoại).
  2. Máy chạy Backend mở CMD gõ "ipconfig" để lấy địa chỉ IPv4 (VD: 192.168.1.15).
  3. Base URL trong app Flutter = "http://192.168.1.15:8080"

--------------------------------------------------------------------------------
PHẦN 3: CƠ CHẾ XÁC THỰC & LƯU TOKEN (AUTH FLOW)
--------------------------------------------------------------------------------
1. Khi người dùng bấm Đăng nhập thành công từ API "POST /api/auth/login":
   - Backend sẽ trả về 1 chuỗi "token".
   - Lưu chuỗi token này vào SharedPreferences.

2. TẤT CẢ CÁC API TIẾP THEO (Xem phòng, thiết bị, thêm sửa xóa...) đều PHẢI gửi
   kèm Header:
   Header:
   {
     "Authorization": "Bearer <chuỗi_token_đã_lưu>",
     "Content-Type": "application/json"
   }

3. Nếu API trả về mã lỗi HTTP 401 (Unauthorized):
   - Nghĩa là token đã hết hạn hoặc không hợp lệ.
   - App tự động xóa token và điều hướng về Màn hình Đăng nhập.

--------------------------------------------------------------------------------
PHẦN 4: CÁC MÀN HÌNH GIAO DIỆN CẦN LÀM (SCREENS)
--------------------------------------------------------------------------------
1. Màn hình Đăng nhập (Login Screen):
   - Ô nhập Tên đăng nhập (tenDangNhap).
   - Ô nhập Mật khẩu (matKhau).
   - Nút "Đăng nhập" -> Lưu token -> Chuyển sang Trang chủ.
   - Nút chuyển qua màn Đăng ký.

2. Màn hình Đăng ký (Register Screen):
   - Các ô nhập: Tên đăng nhập, Mật khẩu, Họ tên, Email, Số điện thoại.
   - Chọn vai trò (Role): "Admin" hoặc "ThanhVien".
   - Nút "Đăng ký" -> Báo thành công -> Quay về Đăng nhập.

3. Màn hình Trang chủ (Dashboard / Home Screen):
   - Thanh trên cùng: Hiển thị "Xin chào, [Họ tên] ([Vai trò])" (Lấy từ GET /api/user/me).
   - Nút Đăng xuất.
   - Danh sách Phòng (Grid view hoặc List view):
     + Hiển thị tên phòng (Phòng khách, Phòng ngủ,...).
     + Số lượng thiết bị trong phòng.
     + Nhấp vào phòng để sang Màn chi tiết phòng.
   - Nếu user là "Admin": Hiển thị thêm nút "+ Thêm phòng mới" (mở dialog nhập tên phòng).

4. Màn hình Chi tiết Phòng & Thiết bị (Room Detail Screen):
   - Hiển thị tên phòng.
   - Danh sách các Thiết bị trong phòng:
     + Tên thiết bị (Đèn trần, Quạt hút, Điều hòa...).
     + Icon tương ứng loại thiết bị.
     + Switch gạt BẬT / TẮT (ON / OFF).
   - Nếu user là "Admin":
     + Nút "+ Thêm thiết bị vào phòng" (nhập tên, loại thiết bị).
     + Nút Sửa / Xóa thiết bị.

--------------------------------------------------------------------------------
PHẦN 5: CHI TIẾT CÁC API BACKEND ĐÃ SẴN SÀNG
--------------------------------------------------------------------------------

1. ĐĂNG KÝ TÀI KHOẢN:
   - Method: POST
   - URL: /api/auth/register
   - Body (JSON):
     {
       "tenDangNhap": "nguyenvana",
       "matKhau": "123456",
       "hoTen": "Nguyễn Văn A",
       "email": "vana@gmail.com",
       "soDienThoai": "0987654321",
       "vaiTro": "Admin"
     }
     (Lưu ý: vaiTro phải là "Admin" hoặc "ThanhVien")
   - Response thành công (200 OK):
     {
       "message": "Tạo tài khoản thành công"
     }

2. ĐĂNG NHẬP LẤY TOKEN:
   - Method: POST
   - URL: /api/auth/login
   - Body (JSON):
     {
       "tenDangNhap": "admin",
       "matKhau": "Admin@123"
     }
   - Response thành công (200 OK):
     {
       "token": "eyJhbGciOiJIUzI1NiJ9.eyJ2YWlUcm8iOiJBZG1pbiIsInN1YiI6Im...",
       "maNguoiDung": 1,
       "hoTen": "Administrator",
       "vaiTro": "Admin"
     }

3. LẤY THÔNG TIN USER HIỆN TẠI:
   - Method: GET
   - URL: /api/user/me
   - Headers: Authorization: Bearer <token>
   - Response (200 OK):
     {
       "tenDangNhap": "admin",
       "hoTen": "Administrator",
       "vaiTro": "Admin"
     }

4. LẤY DANH SÁCH PHÒNG THEO NHÀ:
   - Method: GET
   - URL: /api/phong?maNha=1
   - Headers: Authorization: Bearer <token>
   - Response (200 OK):
     [
       {
         "maPhong": 1,
         "tenPhong": "Phòng Khách",
         "maNha": 1,
         "ngayTao": "2026-09-15T10:00:00",
         "danhSachThietBi": [
           {
             "maThietBi": 1,
             "tenThietBi": "Đèn chùm",
             "loaiThietBi": "Den",
             "trangThai": "TAT"
           }
         ]
       }
     ]

5. XEM CHI TIẾT 1 PHÒNG:
   - Method: GET
   - URL: /api/phong/{maPhong}   (VD: /api/phong/1)
   - Headers: Authorization: Bearer <token>
   - Response: Cấu trúc giống như 1 phần tử trong danh sách phòng ở trên.

6. TẠO PHÒNG MỚI (Yêu cầu quyền Admin):
   - Method: POST
   - URL: /api/phong
   - Headers: Authorization: Bearer <token>
   - Body (JSON):
     {
       "tenPhong": "Phòng Bếp",
       "maNha": 1
     }

7. LẤY DANH SÁCH THIẾT BỊ THEO PHÒNG:
   - Method: GET
   - URL: /api/thiet-bi?maPhong={maPhong}   (VD: /api/thiet-bi?maPhong=1)
   - Headers: Authorization: Bearer <token>
   - Response (200 OK):
     [
       {
         "maThietBi": 1,
         "tenThietBi": "Đèn chùm",
         "loaiThietBi": "Den",
         "trangThai": "TAT",
         "maPhong": 1,
         "ngayTao": "2026-09-15T10:30:00"
       }
     ]

8. THÊM THIẾT BỊ VÀO PHÒNG (Yêu cầu quyền Admin):
   - Method: POST
   - URL: /api/thiet-bi
   - Headers: Authorization: Bearer <token>
   - Body (JSON):
     {
       "tenThietBi": "Quạt thông gió",
       "loaiThietBi": "Quat",
       "trangThai": "TAT",
       "maPhong": 1
     }

PHẦN 6: HƯỚNG DẪN BẮT ĐẦU VỚI GIT
--------------------------------------------------------------------------------
1. Clone repo về máy (nếu chưa clone):
   git clone https://github.com/quangvinhtht2004-source/ConLac.git

2. Tạo nhánh riêng để code (tránh đè code của nhau):
   git checkout -b <ten_ban>_app
   (VD: git checkout -b Huy_app)

3. Khởi tạo dự án Flutter ngay bên trong thư mục "smart-home-frontend":
   cd smart-home-frontend
   flutter create .

4. Khi code xong tính năng nào:
   git add .
   git commit -m "feat(app): lam xong man hinh dang nhap va trang chu"
   git push origin <ten_ban>_app

Chúc bạn code thuận lợi! Có gì vướng mắc về API cứ nhắn trao đổi nhé!
